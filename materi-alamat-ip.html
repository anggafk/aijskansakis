Alamat IP (versi 4)

1. Kelas Alamat IP

Ada lima kelas utama alamat IP, yaitu Kelas A, B, C, D, dan E. Namun, hanya Kelas A, B, dan C yang umum digunakan untuk pengalamatan perangkat dalam jaringan. Kelas D digunakan untuk IP multicasting dan kelas E dicadangkan untuk eksperimen.

Penentuan kelas alamat IP dilihat dari nilai oktet pertama sebuah alamat IP.

KelasRentang Oktet PertamaKeterangan

B128 s.d. 191—
C192 s.d. 223—
D224 s.d. 239Digunakan untuk IP Multicasting
E240 s.d. 255Dicadangkan untuk eksperimen

2. Prefix Length dan Subnet Mask

Prefix length adalah bagian dari alamat IP yang menunjukkan jaringan tempat suatu perangkat berada. Prefix menunjukkan banyaknya binary 1 secara berurutan dimulai dari bit pertama. Prefix digunakan untuk menentukan subnet mask dari alamat IP.

Subnet mask digunakan untuk membedakan network ID dengan host ID, menunjukkan letak suatu host, apakah berada di jaringan lokal atau jaringan luar.

💡
Bit-bit subnet mask yang didefinisikan:
Semua bit yang digunakan oleh Network ID bernilai 1.
Semua bit yang digunakan oleh Host ID bernilai 0.

Alamat IP Kelas C bisa menggunakan Subnetmask kelas C.

3. Alamat Network dan Host

Setiap alamat IP terdiri dari 2 bagian, Alamat Network dan Alamat Host.

Alamat Network (Network ID) merupakan bagian dari alamat IP yang mengidentifikasi jaringan tertentu di mana sebuah perangkat berada. Semua perangkat jaringan harus mempunyai alamat network yang sama untuk bisa saling terhubung.

Alamat Host (Host ID) merupakan bagian dari alamat IP yang mengidentifikasi perangkat spesifik secara individu. Dalam jaringan yang sama, tidak boleh ada 2 atau lebih alamat host yang sama.

Kelas A
Net ID  . Host ID . Host ID . Host ID

Kelas B
Net ID  . Net ID  . Host ID . Host ID

Kelas C
Net ID  . Net ID  . Net ID  . Host ID

Penulisan Alamat IP

Penulisan IP address umumnya adalah dengan 192.168.1.2. Namun adakalanya ditulis dengan 192.168.1.2/24.

Artinya adalah IP address 192.168.1.2 dengan subnet mask 255.255.255.0. Angka /24 berarti bahwa 24 bit pertama subnet mask merupakan bilangan 1.
