Konfigurasi Wireless

💡 Setiap bagian juga disertai Mode CLI sebagai alternatif dari GUI (Winbox). Pada perintah CLI: teks biru adalah perintah tetap (hafalkan), sedangkan teks putih/hitam adalah bagian yang perlu diubah sesuai kebutuhan.

1. Mengaktifkan Interface Wireless

Interface wireless di MikroTik bernama wlan. Interface ini tidak otomatis aktif secara langsung — akan berwarna abu-abu sebagai tanda bahwa interface belum aktif.

  1. a
    Buka menu Wireless → Interfaces.
  2. b
    Pilih interface wlan dan aktifkan dengan menekan tombol ✔.
Mode CLI 
/interface wireless enable wlan1

2. Konfigurasi wlan

  1. a
    Klik 2x pada wlan.
  2. b
    Pilih Tab Wireless.
  3. c
    Isikan sesuai ketentuan berikut:
    Mode: [Mode Wireless]
    SSID: [Nama Jaringan Wireless]
  4. d
    Klik tombol Apply → OK.
💡 Pilihan mode wireless:
Sebagai Pemancar: AP Bridge
Sebagai Penerima: Station
Mode CLI 
/interface wireless set wlan1 mode=ap-bridge ssid=Wifi-TKJ

3. Konfigurasi Keamanan

  1. a
    Buka menu Wireless.
  2. b
    Pilih Tab Security Profiles.
  3. c
    Klik tombol + untuk membuat password.
  4. d
    Isikan sesuai ketentuan berikut:
    Name: [Nama Profil]
    Mode: dynamic keys
    Authentication Types: WPA2 PSK
    WPA Pre Shared Key: [Password]
  5. e
    Klik tombol Apply → OK.
  6. f
    Masuk kembali ke pengaturan wlan pada langkah sebelumnya.
  7. g
    Di parameter Security Profile, pilih nama profil yang sudah dibuat.
  8. h
    Klik tombol Apply → OK.
Mode CLI 
/interface wireless security-profiles add name=profil-wifi mode=dynamic-keys authentication-types=wpa2-psk wpa2-pre-shared-key=password123
/interface wireless set wlan1 security-profile=profil-wifi
