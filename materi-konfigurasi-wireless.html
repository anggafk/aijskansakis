Konfigurasi Wireless

1. Mengaktifkan Interface Wireless

Interface wireless di MikroTik bernama wlan. Interface wlan tidak otomatis aktif secara langsung. Interface wlan akan berwarna abu-abu sebagai tanda bahwa interface wlan tidak aktif.

a. Buka menu Wireless/Interfaces.

b. Pilih interface wlan dan aktifkan dengan menekan tombol ✔.

2. Konfigurasi wlan

Merubah nama Router MikroTik.

a. Klik 2X pada wlan.

b. Pilih Tab Wireless

c. Isikan sesuai ketentuan berikut:

Mode: [Mode Wireless]
SSID: [Nama Jaringan Wireless]

d. Klik tombol Apply → OK.


Pilihan mode wireless

Sebagai Pemancar: AP Bridge
Sebagai Penerima: Station

3. Konfigurasi Keamanan

a. Buka menu Wireless.

b. Pilih Tab Security Profiles.

c. Klik tombol + untuk membuat password.

d. Isikan sesuai ketentuan berikut:

Name: [Nama Profil]
Mode: dynamic keys
Authentication Types: [WPA2 PSK]
WPA Pre Shared Key: [Password]

e. Klik tombol Apply → OK.

f. Masuk ke pengaturan wlan di langkah sebelumnya.

g. Di parameter Security Profile, pilih nama profil yang sudah dibuat.

e. Klik tombol Apply → OK.
