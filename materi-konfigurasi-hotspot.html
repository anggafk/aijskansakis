Konfigurasi Hotspot

💡 Setiap bagian juga disertai Mode CLI sebagai alternatif dari GUI (Winbox). Pada perintah CLI: teks biru adalah perintah tetap (hafalkan), sedangkan teks putih/hitam adalah bagian yang perlu diubah sesuai kebutuhan.

1. Membuat Hotspot

  1. a
    Buka IP → Hotspot → Servers. Menu ini menampilkan daftar Hotspot yang sedang berjalan dan interface yang digunakan.
  2. b
    Klik tombol Hotspot Setup.
  3. c
    Atur sesuai ketentuan berikut:
    Interface: [Port yang dipakai]
    Local Address: [IP Gateway]
    Address Pool: [Rentang IP DHCP]
    Certificate: None
    SMTP Server: 0.0.0.0
    DNS Server: [IP DNS]
    DNS Name: [Alamat Login Hotspot]
    Hotspot User: [user hotspot]
💡 Pengisian DNS Name disesuaikan dengan format alamat web: [Nama Domain].[top level domain]. Contoh: skansakis.net, tkj.skansakis, login.hotspot.
Mode CLI 
/ip hotspot add name=hotspot1 interface=ether2 address-pool=rentang_dhcp
/ip hotspot profile set default dns-name=login.hotspot

2. Konfigurasi Server Profiles

Konfigurasi sistem hotspot, misalnya merubah alamat login, tampilan login, dan metode login. Langkah berikut mengatur agar user tidak tersimpan di satu perangkat.

  1. a
    Buka IP → Hotspot → Server Profiles.
  2. b
    Klik 2x pada hotspot yang sudah dibuat.
  3. c
    Pilih tab Login, lalu hapus tanda ✔ pada Cookie.
  4. d
    Klik tombol Apply → OK.
Mode CLI 
/ip hotspot profile set default use-cookie=no

3. Konfigurasi Profil User

Mengatur batasan dan mengelompokkan beberapa user.

  1. a
    Buka IP → Hotspot → User Profiles.
  2. b
    Klik tombol + untuk membuat profil baru.
  3. c
    Atur sesuai ketentuan berikut:
    Name: [Nama Profil]
    Session timeout: [Batas waktu user untuk login dalam satu sesi]
    Shared user: [Banyak pengguna yang bisa login bersamaan]
    Rate Limit: [bandwidth]
  4. d
    Klik tombol Apply → OK.
💡 Rate Limit dibagi menjadi 2, rx (penerimaan/download) dan tx (pengiriman/upload), dipisahkan dengan garis miring. Contoh: 1M/1K — M untuk Mbps, K untuk Kbps. Artinya kecepatan download 1 Mbps dan upload 1 Kbps.
Mode CLI 
/ip hotspot user profile add name=siswa session-timeout=01:00:00 shared-users=1 rate-limit=1M/1M

4. Konfigurasi User

Berisi daftar semua akun atau user hotspot.

  1. a
    Buka IP → Hotspot → Users.
  2. b
    Klik tombol + untuk membuat user baru.
  3. c
    Tab General:
    Servers: [Hotspot yang digunakan]
    Name: [Nama User]
    Password: [Kata Sandi]
    Profile: [Profil User yang digunakan]
  4. d
    Tab Limits:
    Limit uptime: [Batas waktu user bisa digunakan]
    Limit bytes in: [Batas kuota download]
    Limit bytes out: [Batas kuota upload]
    Limit bytes total: [Batas kuota download & upload]
  5. e
    Klik tombol Apply → OK.
Mode CLI 
/ip hotspot user add server=hotspot1 name=siswa01 password=12345 profile=siswa

5. Menu Lain

  1. a
    Active: memantau user yang sedang digunakan.
  2. b
    Hosts: memantau perangkat yang terhubung dengan jaringan wireless, baik yang sudah maupun belum login.
  3. c
    IP Binding: membuat pengecualian dari perangkat yang terhubung dengan hotspot.
  4. d
    Walled Garden: membuat pengecualian untuk situs atau aplikasi yang bisa diakses tanpa login hotspot.
