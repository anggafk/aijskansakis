Konfigurasi Hotspot

1. Membuat Hotspot

a. Buka IP → Hotspot → Servers.

Menampilkan daftar Hotspot yang sedang berjalan dan interface yang digunakan

b. Klik tombol Hotspot Setup.

c. Atur sesuai ketentuan berikut:

Interface: [Port yang dipakai]
Local Address: [IP Gateway]
Address Pool: [Rentang IP DHCP]
Certificate: None
SMTP Server: 0.0.0.0
DNS Server: [IP DNS]
DNS Name: [Alamat Login Hotspot]
Hotspot User: [user hostspot]

Keterangan:
Pengisian DNS Name disesuaikan dengan format alamat web
[Nama Domain] [tanda titik] [top level domain]
Contoh: skansakis.net, tkj.skansakis, login.hotspot

2. Konfigurasi Server Profiles

Konfigurasi sistem hotspot. Contoh, merubah alamat login, tampilan login, dan metode login.

pengaturan agar user tidak tersimpan di satu perangkat.

a. Buka IP → Hotspot → Server Profiles.

b. Klik 2X hotspot yang sudah dibuat.

c. Pilih tab Login

Hapus tanda ✔ pada Cookie

d. Klik tombol Apply → OK.


3. Konfigurasi Profil User

Mengatur batasan dan mengelompokkan beberapa user.

a. Buka IP → Hotspot → User Profiles.

b. Klik tombol + untuk membuat profil baru.

c. Atur sesuai ketentuan berikut:

Name: [Nama Profil]
Session timeout: [Batas waktu user untuk login dalam satu sesi]
Shared user: [Banyak pengguna yang bisa login bersamaan]
Rate Limit: [bandwidth]

e. Klik tombol Apply → OK.


Keterangan:
Rate Limit dibagi menjadi 2, rx dan tx, dan dipisahkan dengan garis miring.
Rx adalah penerimaan data (download)
Tx adalah pengiriman data (upload)
Contoh: 1M/1K
M untuk Mbps, K untuk Kbps
Dari contoh ini, kecepatan download adalah 1 Mbps dan kecepatan upload adalah 1 Kbps

4. Konfigurasi User

Berisi daftar semua akun atau user hotspot.

a. Buka IP → Hotspot → Users.

b. Klik tombol + untuk membuat user baru.

c. Tab General:

Servers: [Hotspot yang digunakan]
Name: [Nama User]
Password: [Kata Sandi]
Profile: [Profil User yang digunakan]

d. Tab Limits:

Limit uptime: [Batas waktu user bisa digunakan]
Limit bytes in: [Batas kuota download]
Limit bytes out: [Batas kuota upload]
Limit bytes total: [Batas kuota download & upload]

e. Klik tombol Apply → OK.


5. Menu Lain

a. Active: Berfungsi untuk memantau user yang sedang digunakan.

b. Hosts: Berfungsi untuk memantau perangkat yang terhubung dengan jaringan wireless, baik yang sudah maupun belum login.

c. IP Binding: Berfungsi untuk membuat pengecualian dari perangkat yang terhubung dengan hotspot.

d. Walled Garden: Berfungsi untuk membuat pengecualian untuk situs atau aplikasi yang dibuka dengan hotspot.
