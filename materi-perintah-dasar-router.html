Perintah Dasar Router (CLI MikroTik)

Selain menggunakan Winbox (GUI), Router MikroTik juga bisa dikonfigurasi melalui CLI (Command Line Interface) dengan mengetikkan perintah langsung di jendela New Terminal. Halaman ini berisi kumpulan perintah CLI yang sering digunakan, mulai dari navigasi menu, konfigurasi, troubleshooting, sampai menghapus pengaturan.

💡 Pada perintah CLI: teks biru adalah perintah tetap (hafalkan), sedangkan teks putih/hitam adalah bagian yang perlu diubah sesuai kebutuhan.

A. Navigasi Menu

Struktur menu CLI MikroTik berbentuk folder bertingkat, mirip direktori. Perintah berikut digunakan untuk berpindah antar menu.

PerintahFungsi
/Kembali ke menu paling awal (root)
..Kembali satu tingkat menu ke atas
?Menampilkan daftar perintah yang tersedia di menu saat ini
[Tab]Melengkapi otomatis (auto-complete) nama perintah atau parameter
Mode CLI 
# Pindah langsung ke menu IP Address tanpa harus bertahap
/ip address

# Kembali ke menu utama dari mana pun posisi saat ini
/

B. Perintah Konfigurasi

Digunakan untuk menambah, mengubah, mengaktifkan, atau menonaktifkan suatu konfigurasi.

PerintahFungsi
addMenambahkan konfigurasi/data baru
set [nomor] parameter=nilaiMengubah parameter dari konfigurasi yang sudah ada
enable [nomor]Mengaktifkan kembali konfigurasi/aturan yang nonaktif
disable [nomor]Menonaktifkan konfigurasi/aturan tanpa menghapusnya
💡 [nomor] adalah angka urutan (index) baris konfigurasi, bisa dilihat di kolom paling kiri saat perintah print dijalankan. Dimulai dari 0.
Mode CLI 
# Menambah alamat IP baru
/ip address add address=192.168.10.1/24 interface=ether1

# Mengubah hostname router (baris ke-0)
/system identity set name=Router-TKJ

# Menonaktifkan rule firewall baris ke-2
/ip firewall filter disable 2

# Mengaktifkan kembali rule firewall baris ke-2
/ip firewall filter enable 2

C. Melihat Informasi & Troubleshooting

Digunakan untuk memeriksa konfigurasi yang sudah dibuat, memantau kondisi jaringan, dan mencari sumber masalah koneksi.

PerintahFungsi
printMenampilkan daftar konfigurasi pada menu tersebut
print detailMenampilkan daftar konfigurasi beserta detail lengkap tiap parameter
monitor [nomor]Memantau status suatu konfigurasi secara langsung (real-time)
ping [tujuan]Menguji koneksi ke suatu alamat IP atau domain
traceroute [tujuan]Melacak jalur/rute yang dilewati paket data menuju suatu tujuan
Mode CLI 
# Melihat semua alamat IP yang terpasang di router
/ip address print

# Memantau traffic (kecepatan data masuk/keluar) di ether1 secara real-time
/interface monitor-traffic ether1

# Melihat penggunaan CPU, RAM, dan uptime router
/system resource print

# Menguji koneksi ke internet
ping google.com

# Melacak rute paket data menuju suatu alamat
traceroute 8.8.8.8
💡 Tekan tombol Ctrl + C untuk menghentikan perintah yang berjalan terus-menerus, seperti ping, monitor, atau monitor-traffic.

D. Menghapus Konfigurasi

Digunakan untuk menghapus satu atau beberapa baris konfigurasi, sampai menghapus seluruh pengaturan router.

PerintahFungsi
remove [nomor]Menghapus satu baris konfigurasi
remove [nomor1,nomor2]Menghapus beberapa baris konfigurasi sekaligus
/system reset-configurationMenghapus seluruh konfigurasi router dan mengembalikan ke pengaturan awal
Mode CLI 
# Menghapus alamat IP baris ke-1
/ip address remove 1

# Menghapus 3 rule firewall sekaligus (baris ke-0, 1, dan 3)
/ip firewall filter remove 0,1,3

# Reset total seluruh konfigurasi router (tanpa konfigurasi default)
/system reset-configuration no-defaults=yes
💡 Perintah remove dan reset-configuration tidak bisa dibatalkan. Pastikan nomor baris atau konfigurasi yang dihapus sudah benar sebelum menekan Enter.

E. Backup & Export Konfigurasi

Digunakan untuk menyimpan salinan konfigurasi router, agar bisa dipulihkan kembali jika terjadi kesalahan atau saat mengganti perangkat.

PerintahFungsi
/system backup save name=[nama]Membuat file backup (.backup) — hanya bisa dibaca oleh RouterOS
/system backup load name=[nama]Memuat kembali (restore) file backup
/export file=[nama]Mengekspor konfigurasi ke file .rsc berupa teks perintah, bisa dibaca & diedit manual
/import file-name=[nama].rscMenjalankan kembali file konfigurasi .rsc
Mode CLI 
# Membuat file backup
/system backup save name=backup-router-tkj

# Mengekspor konfigurasi ke file teks .rsc
/export file=konfigurasi-router-tkj

F. Perintah Umum Lainnya

PerintahFungsi
/system identity printMelihat nama (hostname) router
/system routerboard printMelihat informasi hardware router (model, versi RouterOS, dsb)
/system clock printMelihat tanggal & waktu router
/user printMelihat daftar user yang bisa login ke router
/system rebootMerestart (nyalakan ulang) router
/system shutdownMematikan router
