Firewall Filter

A. Pengertian

Firewall Filter adalah sistem penyaring lalu lintas data yang bertugas sebagai penentu apakah sebuah paket data boleh lewat atau harus dihentikan. Filter adalah "pintu gerbang" yang memastikan hanya data yang diinginkan dan aman saja yang bisa masuk atau keluar dari jaringan.

Fungsi utama Filter:

a. Keamanan (Security)

Melindungi router dan jaringan lokal dari serangan luar, seperti percobaan hacking, brute force, atau virus/malware.

b. Pengendalian Akses (Access Control)

Mengatur siapa saja yang boleh mengakses layanan tertentu.

c. Optimasi Jaringan

Melindungi router dan jaringan lokal dari serangan luar, seperti percobaan hacking, brute force, atau virus/malware.

B. Konfigurasi Filter

a. IP → Firewall → Filter Rules.

b. Klik tombol + untuk menambah Filter.

c. Atur parameter sesuai kebutuhan:

*lihat poin C

d. Klik tombol Apply → OK.


C. Penjelasan Parameter

1. Chain

Chain adalah arah lalu lintas data. Chain yang dibagi menjadi 3 chain utama.

a. Input: Menangani paket yang menuju ke router.

b. Output: Menangani paket yang keluar dari router.

c. Forward: Menangani paket yang melewati router.

2. Action

Menentukan keputusan yang diambil oleh router terhadap paket tersebut.

a. Accept

Paket diizinkan lewat. Router berhenti memeriksa aturan lain untuk paket yang sama.

b. Drop

Paket ditolak tanpa pesan. Pengirim tidak tahu apakah paketnya sampai atau tidak.

c. Reject

Paket ditolak, tapi router mengirimkan pesan balik kepada pengirim.

d. Log

Router akan mencatat informasi paket ke dalam menu System > Log.

e. Add Source to Address List

IP pengirim paket akan dimasukkan ke dalam daftar IP di tab Address Lists.

f. Add Destination to Address List

IP tujuan paket akan dimasukkan ke dalam daftar IP di tab Address Lists.

3. Parameter (Kondisi)

Kriteria spesifik yang digunakan oleh router untuk mengidentifikasi paket. Parameter diisikan sesuai dengan kebutuhan.

Asal & Tujuan

a. Src. Address

Alamat IP asal paket.

b. Dst. Address

Alamat IP tujuan paket.

*) Format pengisian Src. & Dst. Address:

IP Tunggal. Contoh: 192.168.10.1

Digunakan untuk satu perangkat spesifik

IP Network. Contoh: 192.168.10.0/24

Digunakan untuk semua perangkat dalam satu jaringan.

Rentang IP. Contoh: 192.168.10.11-192.168.10.20

Digunakan untuk perangkat dengan IP yang berurutan.

c. In. Interface

Port/interface tempat masuk paket.

d. Out. Interface

Port/interface tempat keluar paket.

Protocol & Port

e. Protocol

ICMP: Cek koneksi (ping, traceroute)

TCP: Web browsing, Email, Transfer File

UDP: Game Online, Streaming, Voice Call

f. Dst. Port

21: ftp

22: ssh

23: telnet

53: dns

67 & 68: dhcp

80: http

443: https


g. Content

Berfungsi sebagai "Penyaring Kata kunci". Jika sebuah paket data mengandung kata yang kita tentukan (seperti nama situs atau jenis file), maka router akan menangkap paket tersebut.

h. Time

Berfungsi untuk mengatur masa aktif sebuah aturan (rule) berdasarkan jadwal waktu dan hari yang telah ditentukan secara spesifik.

4. Lain-lain

a. Comment (Catatan/Keterangan)

Digunakan untuk memberikan label atau keterangan pada sebuah aturan.
Membantu mengenali sebuah aturan tanpa harus melihat satu per satu (Contoh: "Blokir Youtube").
Memudahkan kolaborasi antar admin dalam satu tim.

b. Simbol Negasi / !

Kotak yang berada di sebelah kiri parameter.
Berfungsi sebagai operator "Bukan" atau "Kecuali" terhadap parameter yang ditentukan.
Contoh: Src. Address: ! 192.168.1.1. Artinya paket berasal dari perangkat dengan IP selain 192.168.1.1

c. enable ✔ dan disable ✘

Mengaktifkan atau menonaktifkan sebuah aturan tanpa harus menghapusnya.
Bisa digunakan untuk mencari tahu apakah aturan tersebut yang menyebabkan gangguan koneksi.

d. Urutan (# / index)

Menentukan urutan router dalam menjalankan Aturan / Rule.
