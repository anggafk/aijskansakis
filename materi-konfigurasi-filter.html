Firewall Filter

💡 Bagian ini juga disertai Mode CLI sebagai alternatif dari GUI (Winbox). Pada perintah CLI: teks biru adalah perintah tetap (hafalkan), sedangkan teks putih/hitam adalah bagian yang perlu diubah sesuai kebutuhan.

A. Pengertian

Firewall Filter adalah sistem penyaring lalu lintas data yang bertugas menentukan apakah sebuah paket data boleh lewat atau harus dihentikan. Filter berperan sebagai "pintu gerbang" yang memastikan hanya data yang diinginkan dan aman saja yang bisa masuk atau keluar dari jaringan.

Fungsi Utama Filter

a. Keamanan (Security) — Melindungi router dan jaringan lokal dari serangan luar, seperti percobaan hacking, brute force, atau virus/malware.

b. Pengendalian Akses (Access Control) — Mengatur siapa saja yang boleh mengakses layanan tertentu.

c. Optimasi Jaringan — Membantu menjaga performa jaringan dengan menyaring lalu lintas data yang tidak diperlukan.

B. Konfigurasi Filter

  1. a
    IP → Firewall → Filter Rules.
  2. b
    Klik tombol + untuk menambah Filter.
  3. c
    Atur parameter sesuai kebutuhan (lihat penjelasan parameter di bagian C).
  4. d
    Klik tombol Apply → OK.
Mode CLI — Contoh: Blokir Ping dari Luar 
/ip firewall filter add chain=input protocol=icmp in-interface=ether1 action=drop
Mode CLI — Contoh: Blokir Situs Tertentu 
/ip firewall filter add chain=forward content=youtube.com action=drop

C. Penjelasan Parameter

1. Chain

Chain adalah arah lalu lintas data, dibagi menjadi 3 chain utama:

a. Input — Menangani paket yang menuju ke router.

b. Output — Menangani paket yang keluar dari router.

c. Forward — Menangani paket yang melewati router.

2. Action

Menentukan keputusan yang diambil oleh router terhadap paket tersebut.

a. Accept — Paket diizinkan lewat. Router berhenti memeriksa aturan lain untuk paket yang sama.

b. Drop — Paket ditolak tanpa pesan. Pengirim tidak tahu apakah paketnya sampai atau tidak.

c. Reject — Paket ditolak, tapi router mengirimkan pesan balik kepada pengirim.

d. Log — Router mencatat informasi paket ke dalam menu System > Log.

e. Add Source to Address List — IP pengirim paket dimasukkan ke dalam daftar IP di tab Address Lists.

f. Add Destination to Address List — IP tujuan paket dimasukkan ke dalam daftar IP di tab Address Lists.

3. Parameter (Kondisi)

Kriteria spesifik yang digunakan router untuk mengidentifikasi paket, diisikan sesuai kebutuhan.

Asal & Tujuan

a. Src. Address — Alamat IP asal paket.

b. Dst. Address — Alamat IP tujuan paket.

💡 Format pengisian Src. & Dst. Address:
IP Tunggal, contoh 192.168.10.1 — untuk satu perangkat spesifik.
IP Network, contoh 192.168.10.0/24 — untuk semua perangkat dalam satu jaringan.
Rentang IP, contoh 192.168.10.11-192.168.10.20 — untuk perangkat dengan IP berurutan.

c. In. Interface — Port/interface tempat masuk paket.

d. Out. Interface — Port/interface tempat keluar paket.

Protocol & Port

e. Protocol

ICMP : Cek koneksi (ping, traceroute)
TCP  : Web browsing, Email, Transfer File
UDP  : Game Online, Streaming, Voice Call

f. Dst. Port

21      : ftp
22      : ssh
23      : telnet
53      : dns
67 & 68 : dhcp
80      : http
443     : https

g. Content — Berfungsi sebagai "penyaring kata kunci". Jika sebuah paket data mengandung kata yang ditentukan (seperti nama situs atau jenis file), router akan menangkap paket tersebut.

h. Time — Berfungsi untuk mengatur masa aktif sebuah aturan (rule) berdasarkan jadwal waktu dan hari yang telah ditentukan.

4. Lain-lain

a. Comment (Catatan/Keterangan) — Digunakan untuk memberi label atau keterangan pada sebuah aturan, membantu mengenali aturan tanpa harus melihat satu per satu (contoh: "Blokir Youtube"), serta memudahkan kolaborasi antar admin dalam satu tim.

b. Simbol Negasi (!) — Kotak di sebelah kiri parameter, berfungsi sebagai operator "Bukan" atau "Kecuali" terhadap parameter yang ditentukan. Contoh: Src. Address: ! 192.168.1.1 artinya paket berasal dari perangkat dengan IP selain 192.168.1.1.

c. Enable (✔) dan Disable (✘) — Mengaktifkan atau menonaktifkan sebuah aturan tanpa harus menghapusnya. Bisa digunakan untuk mencari tahu apakah aturan tersebut yang menyebabkan gangguan koneksi.

d. Urutan (# / index) — Menentukan urutan router dalam menjalankan aturan/rule.
