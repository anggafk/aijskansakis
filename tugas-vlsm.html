Waktu pengerjaan tugas untuk kelas ini sudah selesai.

Instruksi Pengerjaan

  1. Hitung alamat IP menggunakan metode VLSM berdasarkan kebutuhan host di bawah.
  2. Tentukan IP Network, IP Host (Range), dan IP Broadcast untuk setiap ruangan.
  3. Wajib menuliskan proses pengerjaan secara lengkap di kertas folio bergaris. (Halaman belakang gunakan sebagai buram untuk menuliskan proses perhitungan).
  4. Buka form dibagian bawah, jawab pertanyaan berdasarkan hasil perhitungan masing-masing.
  5. Hasil perhitungan IP dikumpulkan ke Mbak Desi Romdani di Kantor TKJ, diurutkan mulai dari nomor presensi kecil.
  6. Pengisian form dan pengumpulan tugas paling lambat pukul 12:15 WIB. (Pengumpulan setelah jam 12:00 WIB, nilai maksimal 80).
