Instruksi Pengerjaan

  1. Kerjakan tugas di Kertas Folio Bergaris. Halaman depan untuk menulis tahapan dan hasilnya, sedangkan halaman belakang digunakan sebagai buram untuk coretan proses perhitungan. Pastikan Nama, Nomor Presensi dan Kelas sudah tertulis jelas di halaman depan.
  2. Hitung alamat IP menggunakan metode VLSM berdasarkan kebutuhan host di bawah. Tentukan IP Network, IP Host (Range), dan IP Broadcast untuk setiap ruangan.
  3. Setelah mendapatkan alamat IP untuk masing-masing ruang, buka form melalui link di bagian bawah lalu jawab pertanyaan pada Form tersebut. Jawaban diambil berdasarkan hasil perhitungan masing-masing.
  4. Serahkan Tugas ke Mbak Desi Romdani di Kantor TKJ. Pastikan lembaran folio sudah urut berdasarkan nomor presensi (dari terkecil ke terbesar).
  5. Batas akhir pengisian form dan pengumpulan fisik adalah pukul 12:00 WIB. (Keterlambatan akan dikenakan sanksi berupa nilai maksimal hanya 80).
