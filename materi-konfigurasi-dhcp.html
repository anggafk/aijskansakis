Dynamic Host Configuration Protocol (DHCP)

Layanan yang memungkinkan perangkat dapat memberikan, meminta, dan menyalurkan alamat IP secara otomatis pada host dalam sebuah jaringan. DHCP juga mampu mendistribusikan informasi IP Address, subnet mask, IP gateway, IP DNS, dan informasi lain sesuai pengaturan yang ditentukan.

A. Konfigurasi DHCP Server

DHCP Server adalah perangkat (dalam hal ini Router MikroTik) yang bertugas memberikan alamat IP secara otomatis kepada client yang terhubung ke jaringan. Konfigurasi DHCP Server terdiri dari tiga bagian utama: menentukan informasi jaringan, menentukan rentang IP yang akan dibagikan, dan mengaktifkan DHCP Server pada port yang diinginkan.

1. Menambahkan IP Gateway, IP Network & IP DNS

  1. a
    IP → DHCP Server → Network.
  2. b
    Klik tombol +.
  3. c
    Atur sesuai ketentuan berikut:
    Address: [IP Network]/[Prefix]
    Gateway: [IP Gateway]
    DNS: [IP DNS]
  4. d
    Klik tombol Apply → OK.
Contoh:
Address : 192.168.10.0/24  (IP Network/Prefix)
Gateway : 192.168.10.1
DNS     : 1.1.1.1
Mode CLI 
/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=1.1.1.1

2. Menambahkan Rentang IP

  1. a
    IP → Pool.
  2. b
    Klik tombol +.
  3. c
    Atur sesuai ketentuan berikut:
    Name: [Nama Rentang IP]
    Addresses: [Rentang IP]
  4. d
    Klik tombol Apply → OK.
Contoh:
Name      : rentang_dhcp
Addresses : 192.168.10.11-192.168.10.30
💡 Rentang IP yang dimasukkan adalah alamat IP yang akan dibagikan ke perangkat client.
Mode CLI 
/ip pool add name=rentang_dhcp ranges=192.168.10.11-192.168.10.30

3. Membuat DHCP Server

  1. a
    IP → DHCP Server → DHCP.
  2. b
    Klik tombol +.
  3. c
    Atur sesuai ketentuan berikut:
    Name: [Nama DHCP Server]
    Interface: [Port yang dipakai]
    Lease Time: [Lama Waktu DHCP]
    Address Pool: [Nama Rentang IP]
  4. d
    Klik tombol Apply → OK.
Contoh:
Name         : dhcp_lab_tkj
Interface    : ether2
Lease Time   : 00:20:00
Address Pool : rentang_dhcp
💡 Lease Time adalah durasi Router meminjamkan alamat IP ke client. Jika perangkat masih terhubung ke jaringan saat waktu habis, lease time akan diperbarui secara otomatis. Jika perangkat sudah tidak terhubung, alamat IP tersebut bisa digunakan oleh perangkat lain. Format penulisan: HH:MM:SS. Contoh 00:20:00 berarti 20 menit.
Mode CLI 
/ip dhcp-server add name=dhcp_lab_tkj interface=ether2 lease-time=00:20:00 address-pool=rentang_dhcp disabled=no

B. DHCP Client

DHCP Client digunakan ketika Router MikroTik bertindak sebagai penerima alamat IP dari perangkat lain (misalnya dari modem ISP). Dengan DHCP Client, Router tidak perlu dikonfigurasi IP secara manual pada port yang terhubung ke ISP — Router akan meminta IP secara otomatis.

1. Menambahkan DHCP Client

  1. a
    IP → DHCP Client.
  2. b
    Klik tombol +.
  3. c
    Atur sesuai ketentuan berikut:
    Interface: [Port yang terhubung ke ISP/modem]
    Use Peer DNS: yes (agar DNS dari ISP digunakan otomatis)
    Use Peer NTP: yes
    Add Default Route: yes (agar gateway otomatis ditambahkan)
  4. d
    Klik tombol Apply → OK.
Contoh:
Interface       : ether1
Use Peer DNS    : yes
Add Default Route: yes
💡 Setelah DHCP Client aktif, Router akan mendapatkan IP, gateway, dan DNS secara otomatis dari ISP. Status bound menandakan IP sudah berhasil diperoleh.
Mode CLI 
/ip dhcp-client add interface=ether1 use-peer-dns=yes use-peer-ntp=yes add-default-route=yes disabled=no

Cek status:
/ip dhcp-client print

C. DHCP Relay

DHCP Relay digunakan ketika DHCP Server dan client berada di jaringan yang berbeda (berbeda subnet). Karena paket DHCP tidak bisa melewati router secara langsung, DHCP Relay bertugas meneruskan permintaan IP dari client ke DHCP Server yang berada di jaringan lain.

1. Menambahkan DHCP Relay

  1. a
    IP → DHCP Relay.
  2. b
    Klik tombol +.
  3. c
    Atur sesuai ketentuan berikut:
    Name: [Nama Relay]
    Interface: [Port yang terhubung ke jaringan client]
    DHCP Server: [IP Asal DHCP Server]
    Local Address: [IP Router pada interface tersebut]
  4. d
    Klik tombol Apply → OK.
Contoh:
Name        : relay_vlan10
Interface   : ether3
DHCP Server : 10.0.0.1
Local Address: 192.168.10.1
💡 DHCP Relay hanya meneruskan permintaan — DHCP Server tetap berada di perangkat lain. Pastikan DHCP Server sudah dikonfigurasi dengan network yang sesuai untuk subnet client.
Mode CLI 
/ip dhcp-relay add name=relay_vlan10 interface=ether3 dhcp-server=10.0.0.1 local-address=192.168.10.1 disabled=no
